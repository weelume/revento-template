# Revento · 创意增长模板

参考站：https://revento.framer.website/ 。33 个页面提供中文与英文；默认中文，英文路径以 /en 开始。包含服务、八组作品、八篇文章、关于、联系和政策。

先读取 .tpl/README.md、.tpl/template.json 和 .tpl/project.json。素材权利见 .tpl/docs/LICENSE.md 与 public/templates/revento/sources.json。

原站显式 /404 入口已注册，并复用 NotFound 页面；独立站 /404 与未知路径返回真实 HTTP 404。共享包消费方可用此入口预览模板错误页，消费方自身路由决定其 HTTP 状态。页面清单为 33 个业务页与一项错误页展示入口，均支持双语。
