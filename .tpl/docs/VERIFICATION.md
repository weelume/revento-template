# 验证

pnpm typecheck、pnpm lint、pnpm test、pnpm build；pnpm tpl:check 检查协议。所有 33 页分别验证中文与英文，未知路径验证真实 404。素材通过 HTTP 下载后比较 SHA256。报告仅记录实际执行项，源码变化后刷新摘要。

内置浏览器检查 PC 1440×1000、iPad 834×1180、H5 390×844，并补测 320px。截图保存真实解码尺寸。交互检查包括菜单 Escape / 焦点 / 锁滚恢复，查询锚点保留，FAQ 高度，流程折叠切图，作品 4→8 与博客 4→8 加载，本地表单提示，以及轮播方向和连续循环。

原站区块初态与当前实现参数分别记录。原站全部三端的精确曲线、时长与拖拽回弹等尚未逐项对齐时，在 reports/motion.json 保持未完成；不得用构建、静态截图或 HTTP 成功代表完整动效验收。

原站显式 /404 入口已注册，并复用 NotFound 页面；独立站 /404 与未知路径返回真实 HTTP 404。共享包消费方可用此入口预览模板错误页，消费方自身路由决定其 HTTP 状态。页面清单为 33 个业务页与一项错误页展示入口，均支持双语。

1.0.1 连续采样比较了参考站与本地圆环/星形角速度及漂移：本地约 +35.996/-39.996 度每秒，参考约 +35.925/-40.011。三端十二张展示图重新采集。全站原站曲线、所有悬停和真实系统减少动态效果仍需以 reports/motion.json 的未验证清单为准。
